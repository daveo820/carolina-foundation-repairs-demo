# Carolina Foundation Repairs: concept site

A pitch demo by LuminArch (luminarch.pro) for Carolina Foundation Repairs, Inc., New Bern NC. **This is not the official site.** The official site is carolinafoundationrepairs.com.

Live: https://daveo820.github.io/carolina-foundation-repairs-demo/ (temporary GitHub Pages link; noindex and robots.txt Disallow all)

- Plain static HTML, CSS and JS. Pages come from `build.py` (run `python3 build.py`).
- Copy and photos come from their current site. Reviews are real Google reviews, quoted word for word. See FACTS_LOG.md.
- Placeholders are tagged in yellow.
- Design notes are in DESIGN_DNA.md. Market research is in market-research.md. Current site renders are in research/.
- Screenshots: screenshots/index-desktop-fold.png, screenshots/index-mobile-fold.png
